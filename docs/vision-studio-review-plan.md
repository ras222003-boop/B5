# قائمة المراجعة المحلية في Basira Training Studio

إضافة صغيرة مبنية على PR #40 (`0fc26f3`) إلى اللوحة القائمة. لا تغير EfficientDet أو الأدوات التدريبية أو سياسات الاعتماد. البيانات والنتائج التشغيلية الخاصة لا تدخل في هذا الطلب.

يقرأ endpoint محلي موثق بجلسة `/api/review-plan` الملف الخاص `.studio/human-review-plan.json` داخل جذر البيانات باستخدام حماية المسارات القائمة. لا يوجد endpoint لكتابة الخطة أو اعتمادها. الملف اختياري؛ عند غيابه تعمل المكتبة كما قبل.

ترتب المكتبة العينات وفق `priority` وتعرض مهام المصدر والأجسام غير المطابقة واقتراحات التصحيح والخصوصية والمجموعات وحقوق المصدر داخل نافذة المراجعة. زر عرض المنطقة يرسم إطارًا للمعاينة فقط؛ لا يغير صناديق الوسوم. الاقتراحات ليست حقيقة مرجعية. مرشح فئة الجمع `candidateClassId` يدخل في التصفية لتسهيل استقبال البيانات غير الموسومة، ولا يدخل في عدادات الوسوم.

تربط كل مهمة بمفتاح العينة وإصدارها وبصمة النسخة النشطة. تحجب الخطة القديمة بعد تعديل العينة أو الصورة، وتعرض عدد الخطط المحجوبة. تتحقق من حدود حجم الخطة والأولويات والفئات والصناديق والدرجات، وترفض مفاتيح مكررة ومدخلات غير سليمة. أية حقول approval في الملف تُهمل؛ جميع المهام ترجع `candidate_only_human_required`.

مثال تخطيطي فقط، لا بيانات أو اعتماد فعلي:

```json
{
  "schemaVersion": 1,
  "items": [{
    "key": "REPLACE_WITH_CURRENT_STUDIO_ITEM_KEY",
    "version": 1,
    "imageSha256": "REPLACE_WITH_CURRENT_ACTIVE_SHA256",
    "priority": 1,
    "tasks": [{
      "kind": "source_unmatched",
      "label": "وسم مصدر غير مطابق؛ راجع الصورة والتصنيف، لا تعتبره خطأ مثبتًا",
      "classId": 1,
      "box": [0.1, 0.1, 0.2, 0.3],
      "score": null
    }]
  }]
}
```

المصدر المحلي للخطة نصيحة وإعداد آلي، وليس توقيع المراجع. تظل الحقوق والخصوصية والوسوم بحاجة إلى قرارات فعلية في أدوات Studio القائمة، مع السبب والهوية والوقت والاستقلال عن كل المساهمين. يمكن لمالك المشروع اعتماد بيانات أعدتها الآلة ولم يشارك في إعدادها. إذا حرر الوسوم بنفسه، يبقى منع الاعتماد الذاتي نافذًا ويحتاج مراجعًا مستقلًا.

للدخول الحقيقي أنشئ حساب المراجع مرة واحدة من terminal تفاعلي بـ`node scripts/vision-ai/studio/server.mjs --data-root <private-root> --add-user`، وأعطه أدوار `rights,privacy,labels`. لا توجد كلمات مرور افتراضية أو موافقات نوقعها نيابة عن المستخدم. شروط المشهد والتوسيم الشامل والخصوصية والحقوق والفصل والتجميد ليست جاهزة لمجرد اكتمال قائمة المهام.

اختبارات Node تشمل غياب الخطة، ترتيبها، تجاهل حقول الاعتماد، بقاء البيانات دون تغيير، حجب الإصدار والبصمة القديمة، مدخلات غير سليمة، اشتراط تسجيل الدخول، ورفض الكتابة. اختبار Chrome اصطناعي فقط يثبت الترتيب والتصفية وعرض المنطقة دون حفظ أو اعتماد أو طلب خارجي، ويفحص axe. أعيد اختبار معرض Studio والاستيراد الحي والفيديو الاصطناعي. TypeScript والبناء لا يتطلبان أي بيانات تدريب حقيقية.

```powershell
pnpm test:vision-studio
node scripts/vision-ai/studio/review-plan-browser-test.mjs
```

ملفات التقدم والحقوق والصور والوسوم ونسخ التنقيح والمقاطع تبقى داخل Basira-Vision-Datasets الخاص خارج Git. تقارير المشاركة يجب أن تقتصر على أعداد وحالات ومشكلات غير شخصية، ولا تعد نتائج تحليل الدفعة الصغيرة مقياسًا لدقة نموذج أو تصريح تدريب أو سلامة تنقل.
