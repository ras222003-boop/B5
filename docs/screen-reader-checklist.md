# Screen-reader validation checklist

**Status:** prepared only. Axe is an automated audit and does not constitute a
screen-reader test. No NVDA, VoiceOver, or TalkBack session was run by the
Validation Gate.

For each session, verify headings, landmarks, focus order, form labels and
errors, live status updates, dialog focus and Escape behavior, language and
direction changes, camera start/stop announcements, route uncertainty, and the
ability to stop safely without a pointer.
