# بصيرة — تجربة ARCore Depth الحقيقية للأندرويد

**هذا تطبيق Android أصلي صغير يستخدم ARCore Depth مع صفحة «رؤية بصيرة» نفسها. لا يفعّل تنبيهات الاصطدام أو إرشاد السلالم.**

## Basira Auto Meter داخل رؤية بصيرة

يفتح التطبيق `/navigation/vision` من نسخة بصيرة المنشورة داخل WebView مباشرة؛ تتولى الصفحة زر تشغيل الرؤية وزر Auto Meter. يبدأ ARCore بكاميرا RGB فقط عند تشغيل الرؤية. عند تفعيل Auto Meter، يبدّل التطبيق جلسة ARCore إلى `DepthMode.AUTOMATIC`، وعند إيقافه يعيدها إلى `DISABLED` ويمسح أي قراءة مخزنة. إيقاف الرؤية أو خروج التطبيق يغلق الجلسة. بقي كود مختبر قياس السطح الأوسط للبحث السابق، لكنه لم يعد شاشة بدء التطبيق أو مصدر مسافة الجسم.

للربط بنسختك المنشورة، ابنِ التطبيق مع رابط HTTPS حقيقي:

```sh
gradle -p android/DepthLab :app:assembleDebug -PbasiraVisionUrl=https://YOUR_DOMAIN/navigation/vision
```

يرفض التطبيق الرابط الافتراضي `.example`، والروابط غير HTTPS، والمسارات غير `/navigation/vision`. الجسر `BasiraNativeFrames` متاح للأصل المضبوط وإطار الصفحة الرئيسي فقط، ولا يستخدم `getUserMedia` منفصلًا. يلزم Android System WebView يدعم `WEB_MESSAGE_LISTENER` و`DOCUMENT_START_SCRIPT`، وهاتف يدعم ARCore. يمكن اختبار التعرف على الأجسام دون Depth؛ إذا كان `DepthMode.AUTOMATIC` غير مدعوم فلا تظهر أمتار.

`nextFrame()` يعيد JPEG بحجم 640×480 من `Frame.acquireCameraImage()`، حتى حين يكون القياس متوقفًا. عند تشغيل القياس فقط، يطلب `Frame.acquireDepthImage16Bits()` من **الإطار نفسه**. لأن خريطة ARCore ليست دائمًا بنفس قص الصورة وأبعادها، يعيد تسجيل عمق 64×48 على إحداثيات صورة CPU المقصوصة باستخدام `Frame.transformCoordinates2d(IMAGE_PIXELS → TEXTURE_NORMALIZED)`. الصورة وخريطة العمق بعد التسجيل في اتجاه المستشعر نفسه؛ تدورهما واجهة الويب معًا. يرفض العمق إذا اختلف طابع صورة الكاميرا أو العمق عن طابع `Frame`، أو انخفضت تغطية عينات 0.5–5 متر عن 70٪. في هذه الحالات يستمر RGB ويعاد `depthEnabled:false` و`values:[]` دون رقم. لا تحفظ الإطارات أو ترسلها إلى خادم قياس؛ تبقى أحدث حزمة في الذاكرة لمدة قصيرة ثم تمحى عند الإيقاف.

هذه محاذاة برمجية تحتاج فحصًا بصريًا على أجهزة حقيقية لأجسام على أطراف الصورة، وبأوضاع إضاءة وحركة مختلفة. كما قد يعيد ARCore عمقًا قديمًا في الأجهزة البطيئة، ولذلك يُرفض إذا لم يطابق الطابع تمامًا. لا تعني مطابقة الإطار أن كل بكسل داخل صندوق كشف الجسم ينتمي إلى الجسم؛ ترشيح العمق المختلط في الويب ضروري قبل إظهار مسافة الجسم.

مرجع التنفيذ: [ARCore Depth API](https://developers.google.com/ar/develop/java/depth/developer-guide)، [عقد Frame وتوقيت العمق](https://developers.google.com/ar/reference/java/com/google/ar/core/Frame)، [جسر WebView محصور بالأصل](https://developer.android.com/reference/androidx/webkit/WebViewCompat).

التجميع الآلي يجري عبر `.github/workflows/android-depth-compile.yml` عند فتح Pull Request. لا يتوفر Android SDK أو Gradle أو JDK 17 في بيئة Windows التي كُتب فيها هذا التحديث، لذلك لم يُثبت تجميع APK محليًا أو عمل الحساس على هاتف فعلي. نجاح CI يثبت التجميع فقط؛ اختبار المحاذاة والدقة على جهاز حقيقي شرط مستقل.

## اختبار الدقة المطلوب قبل الاعتماد

على كل جهاز Android مدعوم، قِس من عدسة الكاميرا إلى سطح الجسم بشريط قياس عند 0.5 و1 و2 و3 و4 و5 أمتار. سجل اسم الجهاز وإصدار Android وARCore، ونوع الجسم، والإضاءة، والحركة، وعدد المحاولات المقبولة والمرفوضة. احسب متوسط الخطأ المطلق وP95 ونسبة الرفض **لكل مسافة ولكل جهاز**، مع حالات الأجسام الضيقة واللامعة والشفافة والخلفية المختلطة. لا توجد نتائج جهاز فعلي في هذا المستودع بعد، ولا يجوز ملء جدول النتائج بقيم افتراضية. راجع VoiceOver/TalkBack ونطق العربية والأداء والبطارية قبل اعتماد تجربة المستخدم.

## APK للاختبار دون Google Play

عند Pull Request، يشغّل GitHub Actions فحص تجميع Android. لإرفاق APK قابل لفتح صفحة بصيرة، اضبط متغير المستودع العام `BASIRA_VISION_URL` على رابط HTTPS المنشور المنتهي بـ`/navigation/vision`، أو شغّل workflow يدويًا وأدخل الرابط في `basira_vision_url`. عندها يظهر artifact باسم `basira-auto-meter-android-debug`. دون الرابط ينجح فحص التجميع فقط **ولا ينشر APK غير قابل للاستخدام**. يمكن كذلك بناء APK محليًا بالأمر أعلاه.

ثبّت APK على هاتف يدعم ARCore، ثم فعّل الكاميرا وAuto Meter من صفحة الرؤية. إذا لم يدعم الجهاز Depth API تستمر أسماء الأجسام بالكاميرا RGB وتظهر المسافة غير متاحة. لا تستخدم القياس أثناء المشي أو قرب الشوارع والسلالم قبل اجتياز الاختبارات الميدانية. APK هذا للتجربة، وليس إصدارًا موقّعًا للمتجر.

## مختبر قياس السطح الأوسط السابق

يبقى `MainActivity.java` كمرجع بحثي للقراءة من نافذة 9×9 في مركز خريطة ARCore. لا يبدأ منه التطبيق الآن، ولا يربط قراءة المركز بأي جسم معروف. لا تستخدمه كمصدر أمتار Auto Meter.

## إعداد المطور على Windows

افتح مجلد `android/DepthLab` كمشروع Android مستقل في Android Studio مع JDK 17. تستخدم Gradle 8.11.1 وAndroid SDK 35 وARCore 1.56.0. التطبيق لا يتطلب OAuth أو قاعدة بيانات بصيرة أو متغيرات Manus.
