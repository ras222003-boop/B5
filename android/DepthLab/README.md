# بصيرة — تجربة ARCore Depth الحقيقية للأندرويد

**هذا تطبيق Android أصلي صغير للقياس التجريبي بمستشعر/خوارزمية ARCore Depth، وليس موقع PWA أو 8th Wall SLAM أو خدمة لتفادي الاصطدام.**

## ما يفعله
- يتحقق من دعم ARCore وDepth API قبل تشغيل الكاميرا.
- يعرض معاينة الكاميرا في جلسة ARCore داخل التطبيق نفسه مع علامة المنتصف.
- يأخذ صورة عمق `Frame.acquireDepthImage16Bits()` ويقرأ المنطقة الوسطى 9×9، ويحوّل **المليمترات إلى أمتار**.
- يرفض العينات المتناقضة والناقصة أو خارج نطاق الاختبار المرجعي 0.5 إلى 5 متر، ويزيل الرقم عند فقدان التتبع.
- يوفر زرًا لنطق **آخر قراءة حديثة** فقط. لا يسجل الفيديو ولا يرسل لقطات إلى الخادم.
- يوضح أن القراءة تخص السطح في مركز العدسة وليست المسافة الآمنة أمام القدم أو إلى جسم متعرف عليه.

مصدر Google: https://developers.google.com/ar/develop/java/depth/developer-guide

## كيف تحصل على APK دون نشر Google Play

1. من GitHub افتح PR التجربة Android؛ راقب `Android ARCore depth compile`. إن نجح انتقل إلى `Actions → Android ARCore depth compile → Artifacts → basira-arcore-depth-lab-debug`.
2. حمّل ملف zip وفكّه لتجد ملف `app-debug.apk`.
3. ثبّت APK على **هاتف Android يدعم ARCore Depth** بعد فهم مخاطر التثبيت خارج المتجر، ومن مصدر GitHub هذا فقط. تفعيل خيار تثبيت التطبيقات من مصدر غير معروف قد يختلف حسب الجهاز.
4. عند أول تشغيل، وافق على إذن الكاميرا وتثبيت/تحديث Google Play Services for AR إن طُلب.
5. جرّب سطحًا ثابتًا في مكان آمن، قِس من العدسة بشريط قياس 0.5 و1 و2 و3 و5 متر، وسجل الخطأ يدويًا. قد يحتاج ARCore حركة كاميرا بسيطة ليحسب العمق، ثم يجب الثبات عند الاختبار.
6. إذا لم يدعم الجهاز Depth API فلا يظهر التطبيق أرقامًا تخمينية. لا تستخدمه أثناء المشي أو عند الشوارع أو السلالم.

## ما لا يقدمه بعد
- لا يربط المقياس بالتعرف على كرسي أو سيارة؛ يحتاج ذلك إلى توحيد RGB + Depth من الإطار نفسه وواجهة بصيرة.
- لا يعرض أبعاد عرض/ارتفاع كل جسم.
- لا يبني ملف APK موقّعًا للإصدار التجاري.
- لا يدعم Safari iPhone؛ تحتاج نسخة ARKit الأصلية الموجودة تحت `ios/DepthCalibrationLab`.
- لا يثبت اختبار المحاكي أو نجاح Gradle دقة المستشعر؛ لا يوجد حتى الآن اختبار ميداني على هاتف Android فعلي.

## إعداد المطور على Windows

افتح مجلد `android/DepthLab` كمشروع Android مستقل في Android Studio مع JDK 17. تستخدم Gradle 8.11.1 وAndroid SDK 35 وARCore 1.56.0. التطبيق لا يتطلب OAuth أو قاعدة بيانات بصيرة أو متغيرات Manus.
