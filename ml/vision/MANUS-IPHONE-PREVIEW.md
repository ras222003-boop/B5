# معاينة iPhone مستقلة في Manus

## الحالة

كود المعاينة موجود، لكن **لم تُنشأ جلسة أو تُنشر معاينة في حساب Manus بعد**. رابط المستخدم `/share/iVrHpzfnbmCJq4QwBBRAWq` صفحة إعادة تشغيل مشتركة بعنوان «Set up and preview بصيرة – اختبار قياس الأمتار 8th Wall»، وليس وصول تحرير مثبتًا. تعذر تشغيل أداة المتصفح المحلية حتى بعد إعادة الضبط. لا رابط HTTPS جديد أو اختبار iPhone ناجح حتى اكتمال التنفيذ الفعلي أدناه.

أصل GitHub المؤكد قبل هذه المرحلة: `codex/basira-object-finetune-v3` عند `47ea29e78c1c3d80006d04997c4c5a2a4d97998b`؛ main عند `2456a4604d7dbe0c40e76d100b81aeacf048f69e` ليس آخر التحديثات. فرع المعاينة هو `codex/basira-vision-readiness-v1`. يجب تثبيت **SHA الكامل المنشور في تسليم هذه المرحلة**، ولا يكفي اسم الفرع المتحرك أو SHA الأصل47ea29e.

## التوافق والنسخ

البنية الحالية React19/Vite7 وExpress/Node22 وpnpm10.18.1، وليست تطبيقًا ثابتًا كامل الوظائف. التشغيل الكامل يشترط MySQL وMANUS_JWT_SECRET ويشغّل ترحيلات عند البدء. لا تستعمل DATABASE_URL أو أسرار أو خدمات المشروع الأصلي.

توثيق Manus الرسمي: [Make a Copy](https://manus.im/docs/website-builder/make-a-copy)، [GitHub Integration](https://manus.im/docs/website-builder/github-integration)، [Preview](https://manus.im/docs/website-builder/editing-and-previewing).

1. افتح المشروع الأصلي في حساب مالكه، ودوّن معرّف الجلسة/النشر/النطاق وربط GitHub وحالة التزامه **قراءة فقط**. لا تضغط Sync أو Publish عليه.
2. اختر Settings → General → Make a Copy، باسم «بصيرة — معاينة iPhone». النسخة مستقلة وغير منشورة؛ لا تنقل صفوف قاعدة البيانات أو النطاق. **الأسرار وقيمها تُنسخ بحسب توثيق Manus**: افحص أسماءها في النسخة فقط، وأزل/عطّل اعتمادها على موارد الإنتاج قبل التشغيل. لا تعرض قيم الأسرار في المحادثة.
3. اتصال GitHub لا يُنسخ، والمزامنة المدمجة موثقة مع main. لا تربط النسخة بمزامنة main في B5، ولا تدمج فرع Codex لتجاوز هذا القيد. اطلب من بيئة Manus استيراد/جلب الفرع المحدد في checkout منفصل وتحقق من SHA الكامل. إذا عرضت الواجهة التصدير إلى مستودع جديد فقط، استخدم نسخة مصدر مثبتة في جلسة النسخة دون إعادة ربط المستودع الأصلي. يلزم التحقق داخل Manus من هذه الإمكانية قبل الادعاء بدعمها؛ الوثائق ليست إثبات استيراد فرع لهذا المشروع.
4. قارن شجرة الكود مع checkpoint النسخة قبل الاستبدال. احتفظ بلقطة منفصلة؛ لا تعِد ضبط المشروع الأصلي أو تنقل سجلاته. تختلف وظائف Manus الأحدث عن فرع B5 إن وجدت؛ تُحل التعارضات في النسخة مع اختبارات دون إسقاطها صامتًا.

## مسار الرؤية المعزول الجاهز

لتجربة الكاميرا والنماذج دون لمس أي قاعدة بيانات، يوجد **خادم معاينة للصفحة الحالية** `scripts/manus-preview/server.ts`. لا يستورد auth/DB/الملاحة الخلفية/Studio/خدمات سحابية. ليس بديلًا للنشر الكامل للمنصة: الحسابات والامتحانات والخدمات الشبكية غير متاحة فيه وتعيد503؛ كودها الأصلي محفوظ دون تعديل. إن كان المطلوب اختبار كل المنصة، يلزم إعداد MySQL جديد مستقل وأسرار اختبار جديدة في Manus وإعادة فحص تكاملاتها، قبل تشغيل entry الأصلي. لا تُسمّ نجاح صفحة الرؤية نجاح المنصة كاملة.

في checkout نظيف، Node22 وpnpm من lockfile (دون بيئة Python أو تدريب):

```sh
git fetch origin codex/basira-vision-readiness-v1
git switch --detach <FULL_VERIFIED_PREVIEW_SHA>
test "$(git rev-parse HEAD)" = "<FULL_VERIFIED_PREVIEW_SHA>"
pnpm install --frozen-lockfile
node scripts/manus-preview/build.mjs <FULL_VERIFIED_PREVIEW_SHA>
```

البناء منفصل تحت `.vision-ai/manus-preview/<SHA>/`، دون قراءة env المحلية أو تفعيل SegFormer أو إدراج أوزانه ونسخة العمق النسبي المقيّدة. لا ينسخ مفاتيح أو CA أو وسائط تدريب أو سجلات الجهاز. لا تستخدم Dockerfile الحالي كما هو: لا ينسخ scripts التي يحتاجها backend الجديد، كما أن `pnpm build` العادي ينسخ public بأوزانه المقيّدة. هذا المسار يتجنب العائق دون تعديل Dockerfile الإنتاج أو حذف ملفات أصلية.

نماذج Tiny وV3 المحلية ليست في GitHub. تحضير حزمة منفصلة قبل إرسالها لنسخة Manus، مع صون إشعارات Apache-2.0 ونسب صور التدريب المؤهلة:

```sh
node scripts/manus-preview/prepare-models.mjs .vision-ai/object-quality <NEW_PRIVATE_MODEL_FOLDER> <FULL_VERIFIED_PREVIEW_SHA>
```

الحزمة تقبل فقط Tiny `427cc366…` وV3 `1f0e0887…` المحددين بالبصمة، وترفض V1/V2 وBDD والأقنعة وتغير الملفات. تحتفظ بالترخيص وLINEAGE وDATA-ATTRIBUTIONS ومعرفة بصيرة، بلا صور/فيديو تدريب أو مفاتيح أو checkpoints مقيّدة. منح الناشر للأوزان ليس إعادة تدقيق لكل صور تدريبه التاريخية أو اعتماد منتج. لا تنشر أوزانًا أخرى لمجرد وجودها في المستودع.

لا تتضمن حزمة المصدر وحدها هذه الأوزان؛ يلزم نقل **حزمة النماذج المراجعة فقط** إلى مخزن ملفات النسخة عبر وسيلة Manus المدعومة، ثم التحقق من جميع البصمات. لا تُرفع مجلدات `.vision-ai` أو `.env.local` أو `.vision-test-fixtures` كاملة.

في مخزن أسرار **النسخة الجديدة فقط**:

- `BASIRA_PREVIEW_ORIGIN`: أصل HTTPS الجديد الكامل دون مسار أو شرطة نهائية؛ يمنع نطاق بصيرة الأصلي المعروف، ولا يدعم wildcard أو Origin من الطلب.
- `BASIRA_PREVIEW_ACCESS_USERNAME` و`BASIRA_PREVIEW_ACCESS_PASSWORD`: دخول معاينة جديد، كلمة مرور عشوائية24 حرفًا على الأقل؛ لا تُرسلها في GitHub أو URL.
- `BASIRA_PREVIEW_MODEL_ROOT`: مكان حزمة النماذج المراجعة خارج public.
- `BASIRA_PREVIEW_ENABLE_MODELS=1` يجعل **الخيارات** متاحة فقط بعد التحقق؛ يبقى الاختيار الأول Lite0، والأقنعة والتوجيه الملاحي التجريبي معطلة. بغير1 تبقى الخيارات معطلة.
- `PORT`: منفذ المعاينة الذي عيّنه Manus.

شغّل من جذر المستودع:

```sh
node .vision-ai/manus-preview/<FULL_VERIFIED_PREVIEW_SHA>/server.mjs
```

خادم HTTP الداخلي يحتاج وكيل HTTPS الخاص بالمنصة؛ لا تعرض منفذه مباشرة على الإنترنت. يجب أن يمرر الوكيل Host المطابق للأصل. إن ظهرت403 افحص إعداد وكيل المنصة، ولا تعطل تحقق Host أو تستعمل صلاحيات المشروع الأصلي. يمنع الخادم POST والرفع وجميع APIs غير المسموحة، ويحمي الصفحة والأوزان بالدخول نفسه، ويسمح بسياسة camera/microphone للنطاق نفسه. لا يطلب الميكروفون تلقائيًا ولا يسجل الصوت أو يرسله. لا يقبل شيفرة التطوير أو الشهادات أو .env أو الملفات الاعتباطية.

استخدم رابط المعاينة المنفصل وHTTPS بشهادة عامة يديرها Manus. لا تربط نطاق الإنتاج، ولا تشترِ نطاقًا/خدمة، ولا تقبل تحذيرات TLS أو تثبت CA محلية. إن كانت معاينة Manus مؤقتة تنتهي صلاحيتها فسجل ذلك، ولا تسمّها نشرًا دائمًا.

```sh
node scripts/manus-preview/check-https.mjs https://<NEW_PREVIEW_HOST> <NEW_LOCAL_REPORT.json>
```

هذا الفحص يرفض التحويلات وتجاوز الشهادات، ويتحقق من الصفحة وسياسات الكاميرا/الميكروفون وأصول WASM. نجاحه **ليس اختبار كاميرا أو iPhone**. تحقق من تحميل ONNX وبصماته ومن استدلال صورة مرخصة داخل المتصفح، لا نجاح HTTP فقط.

نجح بناء الالتزام7c7405a من checkout نظيف، ونجحت514/514 اختبارات، واختبار نسخة الواجهة المبنية كشف9 أجسام لكل من Tiny وV3 في صورة التطوير المرخصة، وشغّل مسار الكاميرا والميكروفون البرمجيين وأوقف المسارات، دون رفع وسائط أو خطأ صفحة. هذا العدد ليس9 كشوف صحيحة مثبتة بمرجع جديد. نقل الاختبار HTTP loopback يحاكي Origin عند TLS edge، ولا يختبر شهادة عامة أو حساب Manus أو هاتفًا. تُعاد تجربة entry المجمّع الفعلي بعد أي تعديل في خادم الحزمة؛ السجل النهائي في تسليم/PR المرحلة يحدد SHA المختبر.

## اختبار Safari وVoiceOver الفعلي

افتح `/navigation/vision` في Safari كامل الشاشة من الرابط الجديد، وليس iframe المحادثة. سجّل موديل iPhone وإصدار iOS وSafari والوقت وSHA من `/api/preview/status`، دون معرفات جهاز خاصة.

1. لا تتجاوز أي تحذير شهادة. سجل إن كانت المشكلة وصولًا أو TLS أو دخولًا أو سياسة أذونات.
2. تحقق أن Lite0 هو الافتراضي. اختر Tiny أوV3 صراحة، واقرأ مصدر النتائج وحالة اللون غير المثبت. قارن كل نموذج في الجلسة نفسها بعد التهيئة، دون تجريب نماذج مقيّدة.
3. فعّل الكاميرا بقرار المستخدم، وجرّب جسمين معروفين، وتحريك أحدهما وتغير الإضاءة؛ لا تستخدمه للمشي. راقب تغير إحصاء البكسلات، لا عداد الفيديو وحده. التوقعات ليست مراجع مستقلة.
4. جرّب صورة/فيديو مصرحًا بهما محليًا؛ راقب شبكة المتصفح إن توفر Web Inspector للتأكد من غياب رفع الوسائط. لا ترسل صور المستخدم إلى Manus chat للتشخيص.
5. جرّب إذن الميكروفون واكتشاف مسار audio ثم أوقفه؛ لا يستلزم ذلك تفريغًا صوتيًا سحابيًا. نجاح إذن API ليس جودة فهم كلام. تحقق الصوت المحلي بالعربية من زر الاختبار؛ عند غياب صوت محلي لا تستبدله بخدمة مدفوعة صامتًا.
6. فعّل VoiceOver من الهاتف، وجرّب الوصول إلى اختيار النموذج وتشغيل/إيقاف الكاميرا والوصف والألوان ووضع القارئ. لا تخلط إعلان VoiceOver بنجاح صوت بصيرة. وثّق انقطاع/تكرار الكلام.
7. بعد30 ثانية و3 دقائق، صدّر سجل التجربة المحلي الاختياري. سجل زمن التحليل والمئين95، الإطارات المتعمدة غير المحللة ومعلومات الذاكرة المتاحة. Safari قد لا يوفر heap أو Battery API؛ سجل «غير مقاس»، لا0 أو تقدير مخترع. قياس بطارية أطول يحتاج بروتوكولًا منفصلًا.
8. أوقف الكاميرا وتحقق من انتهاء المسار وزوال مؤشر الاستخدام. ارجع فورًا إلى Lite0. لا تنشئ بيانات تدريب من التجربة ولا تشغل تنبيهًا ملاحيًا.

حتى وصول سجل ونتائج فعلية من الجهاز: `iphoneTested=false` و`voiceOverTested=false`، والدقة الواقعية والألوان والأمان الملاحي غير مثبتة.
