# مسودة قائمة الأجسام (للتعديل) — 2026-10-31

**الغرض:** تحديد الأجسام التي يسمّيها التطبيق للكفيف. عدّلها بالحذف والإضافة وتغيير الأسماء. العلامة ✓ = الكاشف الحالي (Tiny/YOLOX-S) يعرفها أصلًا من فئات COCO؛ وغيرها يحتاج مصنّف أسماء جاهزًا أو رسمًا أو صورًا.
**مبدأ السلامة:** الأجسام التي تهدد السلامة (سلالم، حفر، عوائق أرضية) تُحذَّر منها بأنها «جسم/عائق» حتى لو لم تُعرف التسمية، ولا يُسمّى جسم إلا بثقة معايرة.
