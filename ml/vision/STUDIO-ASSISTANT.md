# المساعد المحلي في Basira AI Training Studio

هذه إضافة إلى [STUDIO.md](STUDIO.md)، تستخدم أدوات الاستيراد والتحقق والتوسيم القائمة. لا يوجد تشغيل تدريب أو توليد سحابي أو اعتماد تلقائي. لا تحتاج API key أو GPU.

## تشغيل واستخدام

من جذر B5 بعد تثبيت اعتماديات المشروع، استخدم الحسابات المحلية القائمة. إن لم توجد، أنشئ هوية لكل شخص باستخدام `--add-user` كما في STUDIO.md، مع فصل المساهم عن المراجع المستقل.

```powershell
$datasets = Join-Path $env:USERPROFILE 'Documents/Basira-Vision-Datasets'
node scripts/vision-ai/studio/server.mjs --data-root $datasets --port 4318
```

افتح `http://127.0.0.1:4318`. في مراجعة العينة:

1. «فحص الجودة» يسجل الدقة والإضاءة والتفاصيل والبيانات الوصفية واكتمال الوسوم. هذه قواعد تقريبية، وليست قياسًا لدقة نموذج أو شهادة خصوصية.
2. «اقتراحات الكشف وOCR» يشغل موفري EfficientDet Lite0 وTesseract الموجودين داخل المتصفح. فعّل OCR صراحة عند الحاجة. المربعات والدرجات اقتراحات؛ يمكن نقل الاقتراح للمحرر ثم حفظ إصدار بسبب واضح. لا يحذف الوسوم الأصلية أو يعتمدها تلقائيًا.
3. يرشح OCR مناطق نصوص مثل البريد أو الهاتف؛ لا يحفظ النص الخام في تقرير المساعد. تحديد الوجوه واللوحات يحتاج نموذجًا متخصصًا أو تحديدًا يدويًا. غياب الاقتراح ليس دليلًا على غياب بيانات شخصية.
4. راجع مناطق التنقيح الحمراء، احذف غير المناسب أو ارسم مناطق إضافية باستخدام وضع التنقيح. أدخل السبب وأكد إنشاء النسخة، ثم قارن الأصل والنسخة. التغطية سوداء صلبة، وليست طمسًا قابلًا للاسترجاع؛ الأصل محفوظ منفصلًا، مع SHA-256 وسجل المناطق والفاعل والوقت. تتجدد مراجعات الحقوق والخصوصية والوسوم. الصور ذات اتجاه EXIF مختلف تحتاج أولًا نسخة مصححة الاتجاه ومراجعة؛ لا تُطبق عليها مربعات في نظام إحداثيات ملتبس.

في «مشكلات تحتاج معالجة»، تتوفر قواعد الجودة للمكتبة، والكشف الجماعي، وOCR جماعي اختياري، وقائمة النوع والإجراء والدرجة وفتح العينة. التشغيل متتابع على CPU/المتصفح وقد يستغرق وقتًا. خطأ أو نتيجة قديمة لا يمنحان اعتمادًا. إطارات الفيديو المستخرجة بالأداة القائمة يمكن تحليلها كصور؛ لا يوجد تحليل آلي كامل للحركة أو الصوت أو تتبع عبر الفيديو في هذه الإضافة.

## التشابه وتقسيم البيانات

الفحص يجمع SHA-256 للبايتات والبكسلات المفككة، ثم dHash مع مقارنة توزيع السطوع ونسبة الأبعاد. يفحص الأصل والنسخة المنقحة. التطابق قطعي ضمن البايتات/البكسلات المقارنة؛ التشابه مرشح غير معاير قد يخطئ أو يفوّت الاقتصاص والدوران والانعكاس والتغييرات الكبيرة. لا يحذف أو يعيد تقسيم الملفات تلقائيًا.

المراجع بدور `labels`، الذي ليس أي مساهم مسجل في العينتين، يسجل «نفس اللقطة/الجلسة» أو «مشهد مستقل» مع السبب والهوية والوقت. لا يمكن استبعاد نسخة متطابقة على أنها مستقلة. القرار مربوط ببصمات الأصل والنسخة الحالية؛ تغيير النسخة يعيد الحاجة للمراجعة. الصور ذات جلسة مشتركة أو فيديو مشترك تبقى مجموعة واحدة عند دمج التشابه المؤكد.

**تصدير لقطة التجهيز من Studio** يتطلب فحصًا كاملًا للفهرس؛ أي خطأ فهرسة أو أكثر من 1000 عينة يحجب التصدير. التشابه غير المحسوم، أو ارتباط نسخة غير مقسمة بعينة مجمدة، أو ارتباط train/test متعارض يحجب التصدير؛ لا ينقل test إلى train. الأداة لا تثبت عدم وجود تشابه مجهول. حافظ على فصل جلسات التصوير الأصلية وعلى استقلال الاختبار.

هذه الحماية الإضافية تخص مسار تصدير Studio، ولا تغيّر مسارات CLI القديمة إلى كاشف تشابه جديد. قبل التدريب اللاحق استخدم لقطة Studio التي مرت بهذا الفحص ثم المدققات والبوابات القائمة. الاستيراد الأولي يبقى منطقة تجهيز غير معتمدة. لا تتجاوز هذا الفحص باستخدام فهرس يدوي بديل.

## الصور الاصطناعية

في القسم المنفصل ارفع PNG/JPEG/WebP جديدة ومستقلة، مع الأداة والنموذج أو «غير معلن»، وصف التوليد، الإعدادات غير السرية وseed إن توفر، وقت ISO، المصدر والترخيص ونص دليل الحقوق. سجل عدم استخدام صور المستخدمين وعدم تعديل أصل مرفوض الحقوق. تعاد الاستفادة من `bundleDraft` و`prepareDraft`؛ لا توجد خدمة توليد أو تنزيل خلف الكواليس.

يحفظ الملف الأصلي ودليل التوليد بحقوق معلقة في `incoming/synthetic-<uuid>/` خارج Git. `contentKind` و`originKind` وبيانات `generation` تفصل الاصطناعي؛ مرشح المكتبة وعدّاداتها توضح هذا الفصل. لا تقسيم آلي أو اعتماد آلي. يمنع مسار البيانات القائم تحويل أصل اصطناعي إلى بيانات تقييم حقيقي أو معايرة بمجرد تغيير `contentKind`. مسار التدريب الحالي يحجب الاصطناعي أيضًا؛ أي استخدام لاحق كتعزيز تدريب يحتاج بروتوكولًا منفصلًا ومراجعة.

رفض الحقوق يبقى بعد تعديل الوسوم، ويحجب التنقيح واعتماد المصدر نفسه. التطابق مع أصل مرفوض يمنع إعادة إدخاله كاصطناعي. كشف الاشتقاق العميق ليس مضمونًا؛ إقرار الاستقلال ودليل المصدر والمراجعة البشرية يظلون ضروريين. استخدم مصدرًا مستقلًا مرخصًا أو توليدًا جديدًا عامًا، لا تعديلًا لتجاوز الحقوق.

## تعاون ChatGPT

«احتياجات البيانات وتقرير ChatGPT» ينشئ معاينة JSON ثم تنزيلًا محليًا اختياريًا. تتضمن أهداف الخطة القائمة لـ35 فئة، الأعداد، أنواع المشكلات ودرجاتها، إحصاء التشابه وطلبات أمثلة اصطناعية عامة. لا تضم الصور أو أسماء الملفات أو روابط المصادر أو النص الخام أو أسماء المراجعين أو قياسات المسافة. راجع الأعداد والتفاصيل قبل مشاركة الملف بنفسك؛ قد تكون أعداد المشروع حساسة أيضًا.

يمكن إرسال طلب مثل:

> راجع هذا التقرير التجهيزي. رتب احتياجات الفئات والظروف والسلبيات الصعبة، واقترح أمثلة جديدة مستقلة ومقاييس تحقق. لا تمنح اعتماد حقوق أو خصوصية أو وسوم، ولا تفسر أعداد الصور أو درجات الكشف كدليل على تحسن الدقة.

اقتراحات ChatGPT تُنفذ كمراجعة بشرية داخل اللوحة، ويُحفظ التعديل بسبب وهوية وإصدار. لا يوجد مسار يقبل ملفًا من ChatGPT كاعتماد أو يرسل الصور إليه تلقائيًا. يمكن لاحقًا مراجعة تقارير تجارب حقيقية مستقلة عبر سجلات التجارب القائمة بعد اعتماد البيانات؛ لم تبدأ تجربة تدريب هنا.

## الخصوصية والحدود

الخادم مقيد بـ127.0.0.1 مع Host/Origin/CSRF والجلسات القائمة. الأصول والنماذج وOCR كلها محلية؛ CSP لا يسمح باتصال خارجي. الملفات المسموح تقديمها من النماذج قائمة ثابتة مع تحقق SHA-256، ولا يوجد endpoint سحابي. أي إضافة سحابية مستقبلية تتطلب مسار موافقة صريحة لكل رفع، وضبط الاحتفاظ والخصوصية، ومراجعة أمنية؛ لا تكفي موافقة تشغيل التحليل المحلي.

التقارير والبصمات وقرارات التشابه والحزم داخل `.studio/assistant/` الخاص. الأصل والنسخ والوسوم والحسابات لا ترفع إلى Git. التحكم بالوصول والروابط الرمزية وصلاحيات الملفات يستخدم الحماية القائمة. حسابات الأشخاص وإدارة Windows ACL مسؤولية مشغل الجهاز؛ امتلاك صلاحية تعديل الملفات الخاصة مباشرة حد ثقة إداري، وليس خصمًا يمنعه هذا الخادم.

الكشف الحالي يغطي فئات COCO المطابقة للتصنيف فقط، ولم يتخصص في عوائق الأرضية. OCR ليس كاشف خصوصية شاملًا. تحتاج الوجوه واللوحات نموذجًا محليًا مرخصًا واختبارات recall على بيانات مستقلة، وتحتاج الحركة والتتبع بيانات فيديو حقيقية مع هوية مسار وtimestamps. لا تُستنتج أمتار أو خطر اصطدام أو اتجاه المستخدم من حجم الصورة أو درجة الكشف.
