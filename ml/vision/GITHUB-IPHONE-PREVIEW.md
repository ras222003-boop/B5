## توافق التشغيل

نجح بناء تطبيق Node الكامل وترحيل قواعد MySQL اختبارية جديدة في GitHub CI؛ **لم تُنفذ عملية استيراد هذا الفرع أو تشغيله داخل حساب Manus**. توافقه هناك مشروط بإتاحة Node/Express وMySQL وإعدادات اختبار مستقلة. النشر الفعلي المنفذ أدناه يستضيف مكونات الرؤية والصوت الحالية فقط على Pages، دون نقل مشروع Manus الأصلي.

## حدود المعاينة وحقوق الملفات

- يظل Lite0 الافتراضي، ويُختار Tiny أوV3 صراحة. درجات النموذج غير معايرة، والألوان غير مثبتة، والأقنعة معطلة.
- إعداد بناء منفصل يضيف بادئة مسار مشروع GitHub إلى أصول/API الرؤية داخل الصفحة والعامل، ويستخدم hash routing للمعاينة. لا يعدل مسارات إنتاج B5 أو محركه الملاحي.
- تعاد الاستفادة من مكوّن Vision الحالي وسياقاته، مع شريط يوضح حدود المعاينة وزر فحص إذن الميكروفون فقط. لا يُحمّل تطبيق الحسابات/الامتحانات أو مساعد سحابي.
- سياسة المتصفح تمنع POST وXHR الكتابي وsendBeacon قبل الإرسال، وتمنع الجلب الخارجي والتفريغ الصوتي الأصلي الذي قد يستخدم خدمة متصفح سحابية. CSP تمنع النماذج والوسائط والخطوط الخارجية وإرسال النماذج. لا PWA/service-worker قديم أو ربط بإنتاج Manus.
- البناء يستبعد كل أوزان SegFormer ونسخة العمق النسبي وSlimSAM وV1/V2/BDD. يبقي فقط Lite0/MediaPipe/ORT وأوزان Tiny وV3 المثبتة بالترخيص وLINEAGE وDATA-ATTRIBUTIONS. لا صور تدريب أو اختبار أو checkpoints أو أسرار أو شهادات محلية في حزمة النشر.
- يجب أن يكون checkout نظيفًا وSHA مطابقًا، وأن تنجح بصمات كل ملف. بناء `--development` يُعلّم `publishable=false` ولا يقبله مغلف النشر. النشر في المستودع المنفصل يدوي؛ push وحده لا ينشر إصدارًا جديدًا.

```sh
node scripts/github-preview/build.mjs <VERIFIED_FULL_SHA> <PRIVATE_QUALIFIED_MODEL_REGISTRY> /basira-iphone-research-preview/ <NEW_BUILD_DIRECTORY>
node scripts/github-preview/smoke.mjs <BUILD_DIRECTORY> <LICENSED_DEVELOPMENT_IMAGE> <NEW_LOCAL_REPORT.json>
node scripts/github-preview/package.mjs <BUILD_DIRECTORY> <NEW_DEPLOYMENT_CHECKOUT> <REVIEWED_THIRD_PARTY_NOTICE_DIRECTORY>
```

يُدفع checkout النشر إلى مستودع المعاينة المنفصل، بفرع `codex/preview`، ثم يُفعّل Pages عبر workflow، ويُشغّل يدويًا بعد الاختبارات. لا CNAME أو نطاق مخصص. يفحص `check-hosted.mjs` HTTPS دون تجاوز الشهادة وجميع الملفات والبصمات من المصدر نفسه، بطلبات Range محدودة وسجل استئناف مرتبط ببصمة البناء.

افتح الرابط في Safari مباشرة، دون تثبيت CA أو قبول تحذير شهادة. اختر Tiny أوV3 صراحة، ثم شغّل الكاميرا واسمح بها. جرّب جسمين معلومين وحركة وإضاءة مختلفة دون مشي، ثم فحص الميكروفون وزر الصوت المحلي ووضع قارئ الشاشة مع VoiceOver. أوقف الكاميرا وتحقق من زوال مؤشرها. صدّر سجل التجربة المحلي الاختياري وأرسل **ملف النتائج دون صور أو فيديو** مع موديل iPhone وإصدار iOS. لا تُحسب التوقعات وسومًا مرجعية. دقة الكشف والألوان والهوية وملاءمة التنقل تحتاج تقييمًا مستقلًا؛ بطارية/حرارة وذاكرة Safari لا تُخمن عند غياب القياس.
