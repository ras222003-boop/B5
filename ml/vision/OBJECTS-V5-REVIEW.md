# مراجعة كشف الأجسام البشرية (2026-10-31)

أداة محلية لمراجعة صناديق الكشف على صور مجموعة الألوان (46 صورة تطوير ومعايرة؛ **قسم الاختبار المغلق لا يُعرض**). المقترحات من Tiny@416 وYOLOX-S@640 معًا بعتبة 0.25 (457 صندوقًا) وهي **ليست حقيقة**: لكل صندوق «صحيح» أو «خطأ» أو تغيير فئة، ويمكن رسم جسم فاته النموذج بالسحب. تأكيد «الصورة مكتملة» يعني أن كل أجسام الفئات المهمة (شخص، كرسي، أريكة، سرير، طاولة، تلفاز، حاسوب، كوب، زجاجة، وعاء، مزهرية، كتاب، حقائب، مظلة، مركبات، مقعد، إشارة مرور، نبتة، ثلاجة) موسومة؛ وحدها الصور المكتملة تدخل حساب الاستدعاء.

```bash
node scripts/vision-objects-v5/review/server.mjs <cohort> <proposals.json> <reviews.jsonl>   # http://127.0.0.1:4391
python scripts/vision-objects-v5/make_proposals.py <cohort> development,calibration <tiny.onnx> <yolox_s.onnx> <proposals.json>
python scripts/vision-objects-v5/eval_against_human.py <cohort> <reviews.jsonl> <out.json> --model tiny=<tiny.onnx>:416 --model yolox-s=<s.onnx>:640
```

الحفظ إضافة فقط (آخر سجل لكل صورة يسري)، والخادم على 127.0.0.1 ولا يرفع شيئًا. الاختبار الذاتي للأداة (على نسخة منفصلة بملف مراجعات مؤقت): قرارات وتغيير فئة ورسم جسم وحفظ وتقدم وقواعد التحقق (اسم المراجع، حسم كل الصناديق قبل «مكتملة»، صناديق وفئات صالحة).
