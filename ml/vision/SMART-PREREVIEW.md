# المراجعة الذكية المسبقة المحلية

توسعة لأدوات Studio الحالية، وليست منظومة تدريب أو محرك إنتاج جديدًا. كل النتائج مرشحات غير معتمدة. لا تُرسل صور أو OCR أو تقارير تلقائيًا إلى ChatGPT أو السحابة.

## التشغيل

```powershell
Set-Location -LiteralPath 'C:\Users\Asus\Documents\ChatGPT\بصيرة\B5'
& 'C:\Program Files\nodejs\node.exe' scripts/vision-ai/studio/server.mjs --data-root 'C:\Users\Asus\Documents\Basira-Vision-Datasets' --port 4318
```

تحقق من العملية القائمة قبل التشغيل؛ لا تبدأ خادمًا ثانيًا على المنفذ نفسه. افتح `http://127.0.0.1:4318/`، ثم «المساعد» ← «المراجعة الذكية المسبقة». الحسابات والجلسات وCSRF وحماية same-origin القائمة محفوظة.

للتجهيز دون تسجيل دخول بشري، شغّل الأمر الصريح المحلي التالي. يستخدم نماذج المتصفح الموجودة ويفتح خادم قراءة مؤقتًا على IPv4 loopback بمنفذ عشوائي ومفتاح خاص في ترويسة العملية فقط؛ يغلقه عند الانتهاء. لا ينشئ حسابًا أو مراجعة بشرية، ولا يسجل نص OCR:

```powershell
& 'C:\Program Files\nodejs\node.exe' scripts/vision-ai/studio/prereview-run.mjs --data-root 'C:\Users\Asus\Documents\Basira-Vision-Datasets'
```

الافتراضي صور حقيقية فقط؛ `--synthetic-only` يشغل قائمة اصطناعية منفصلة. اختبر أولًا باستخدام `prereview-browser-test.mjs` الذي ينشئ مكتبة اصطناعية مؤقتة، لا باستخدام مكتبة حقيقية أعيدت تسميتها. الأمر يجري استدلال CPU وتجهيز بيانات فقط، ولا يبدأ التدريب. تحقق من عزل المزامنة قبل تشغيله على بيانات خاصة.

## ما ينجز آليًا

- يعيد استخدام EfficientDet Lite0 وTesseract والفحص البصري والتشابه الموجودين. لا يغير عتبات أو أصول محرك الإنتاج. فئات العوائق غير الموجودة في COCO تُعلم كغير مدعومة.
- يقارن اقتراحات المربعات والتصنيفات والوسوم الناقصة، ويعرض **الأجسام الأصلية غير المطابقة** أيضًا. لا يحذف وسمًا لغياب كشف مطابق.
- يسجل متوسط السطوع واقتراح إضاءة ضعيفة إن انطبق الحد، كقرينة غير معايرة. لا يحول السطوع أو فئة الجسم إلى «داخل/خارج»؛ المكان وحركة الالتقاط يبقيان بحاجة إلى أدلة. لا يستنتج مسافة مترية.
- يتحقق من وجود مرجع المصدر والترخيص وملف الدليل وبصمته لكل مصدر. بصمة الدليل تحقق سلامة الملف فقط؛ لا تثبت الحقوق التجارية أو السماح بتدريب AI أو الخصوصية.
- ينتج نسخة PNG مستقلة بلا EXIF/XMP/IPTC، مع مناطق التغطية المقترحة. **لا تصبح نشطة ولا معتمدة تلقائيًا**. الحقوق المرفوضة تمنع إنتاج النسخة لتجاوز الرفض.
- يحتفظ بالجلسات المعلنة ويعيد استخدام فحص التشابه الكامل وقرارات المراجع المستقل. عدم التشابه لا يثبت استقلال جلسة التصوير؛ وثق جلسة/فيديو/مصدر اللقطة الفعلي قبل تجميد التقسيم.

## أداة الخصوصية الاختيارية

إعداد إداري محلي خارج Git في `.studio/prereview-cv.json`:

```json
{
  "python": "C:/private-tools/python.exe",
  "sitePackages": "C:/private-tools/opencv-site-packages",
  "cascades": "C:/private-tools/cascades",
  "modelHashes": {
    "haarcascade_frontalface_default.xml": "SHA256_FROM_VERIFIED_DOWNLOAD",
    "haarcascade_profileface.xml": "SHA256_FROM_VERIFIED_DOWNLOAD",
    "haarcascade_russian_plate_number.xml": "SHA256_FROM_VERIFIED_DOWNLOAD"
  }
}
```

استخدم OpenCV **4.12.0.88** المعزول وتبعياته المتوافقة؛ الإصدار 5 لا يوفر CascadeClassifier في العجلة التي اختبرت. لا تثبته على Python العام. نماذج Haar من [OpenCV 4.12.0](https://github.com/opencv/opencv/tree/4.12.0/data/haarcascades)، مع حفظ ملفات الترخيص والمصدر وبصمات التنزيل. [توثيق OpenCV](https://docs.opencv.org/4.x/db/d28/tutorial_cascade_classifier.html) يوضح أنها كواشف متعلمة، لا فحصًا شاملاً للخصوصية. كاشف اللوحات الروسية محدود بنطاقه ولم يعتمد للوحات السعودية. لا يحدث تنزيل أو اتصال شبكي عند التحليل.

لا تتحول نتيجة صفر أو تعطل الأداة إلى «خالٍ من البيانات الشخصية». يظل فحص الوجوه واللوحات والنصوص والخلفيات والأفراد والبيانات غير النصية مسؤولية بشرية. جميع الدرجات غير معايرة. لا تعد هذه الأداة تعريفًا بالأشخاص أو خدمة للتعرف على الوجوه.

## عمل المُعدّ والمراجع

1. يدخل المُعدّ بنفسه، ويفتح صورة من القائمة الحقيقية المرتبة لتقليل النواقص. يستعرض الصورة والمربعات والأدلة والنواقص والمقارنة. اقتراحات التصحيح غير محددة افتراضيًا.
2. يحدد فقط الاقتراحات التي فحصها؛ يمكنه تسجيل رفض تجهيزي صريح للاقتراح الخاطئ، وغير المحدد يبقى مؤجلًا ولا يعد رفضًا. يكتب سببًا ويؤكد فحصه ثم يحفظ إصدار وسوم. لا يكتب الوسوم من الصفر. يمكنه تصحيح صفات الحجب والاقتطاع والأرضية والظروف في المحرر القائم. الظروف غير المؤكدة تحفظ «غير مراجعة»، وتمنع اجتياز بوابة الوسوم النهائية.
3. إن احتاج النسخة المنقحة، يفحص التغطية ثم يفعّلها كتصحيح مستقل. يستطيع نقل المناطق المقترحة إلى محرر التنقيح الموجود لحذف الخاطئ وإضافة الناقص دون إعادة إدخالها. هذا يعيد بوابات المراجعة ويجعل التقرير السابق للقراءة فقط. يمكن إعادة التحليل؛ تبقى النسخة القديمة والأصل محفوظين. المعاينة لا تثبت كفاية التنقيح.
4. يدخل المراجع بنفسه؛ يفحص كل عينة وأدلتها في المحرر القائم، ويسجل قرارات الحقوق والخصوصية والوسوم وأسبابها بصورة مستقلة. لا تتخذ أدوات التجهيز هذه القرارات ولا تستعمل كلمة مرور أحد. يرفض الخادم مراجعة أي مساهم سابق لعمله حتى إذا تغير المُعدّ لاحقًا.
5. راجع أزواج التشابه في القسم القائم. ربط الصور أو تمييزها قرار مستقل مسبب؛ لا تحذف الأصول. صور الجلسة/الفيديو الواحد والمحتوى المتطابق يبقون في مجموعة واحدة.
6. يستطيع المراجع اختيار **بعض العينات الحقيقية المعتمدة** لتجهيز لقطة، دون انتظار بقية المكتبة. يعاد استخدام التحقق الحالي وreleaseGroups، ويمنع التشابه غير المحسوم وتسرب التقسيم المجمد. اللقطة ليست إذن تدريب؛ يلزم تجميد تقسيم ومجموعة اختبار مستقلة لم تستخدم للتشخيص/التحسين، ثم اعتماد خطة التدريب والتكلفة.

## التدقيق والاختبارات

التقارير والمسودات: `.studio/prereview/reports/` و`drafts/` داخل التخزين الخاص؛ تقرير الدفعة `batch-*.json`. ترتبط بإصدار العينة وبصمة الصورة والفهرس. يثبت سجل تعديل العينة بصمة التقرير، المنتج الآلي، معرفات المقترحات المختارة، هوية المُعدّ ووقت وسبب الحفظ. لا يقبل الخادم حقل هوية/اعتماد من المتصفح بدلاً من الجلسة. بيانات النموذج القادمة من المتصفح تظل اقتراحات غير موثقة كحقيقة.

```powershell
& 'C:\Program Files\nodejs\node.exe' --test scripts/vision-ai/studio/prereview.test.mjs
# اختياري لاختبار OpenCV المهيأ؛ ملف إعداد لا يحتوي كلمات مرور
$env:BASIRA_TEST_CV_CONFIG = 'C:\private-tools\config.json'
& 'C:\Program Files\nodejs\node.exe' scripts/vision-ai/studio/prereview-browser-test.mjs
```

الاختبارات تستخدم حسابات وقرارات اصطناعية فقط. لا يثبت نجاح الاختبار دقة الكواشف على بيانات حقيقية. للمشاركة مع ChatGPT، أنشئ تقريرًا تجميعيًا منزوع الصور وأسماء الملفات وهوية الأشخاص ونصوص OCR؛ لا ترسل سجلات المكتبة الخام.
