بانتظار الفهرسة

تستخدم المراجعة التصفية وترتيب الأولوية الحاليين. لكل صورة قرارات منفصلة للحقوق والخصوصية والوسوم، مع سبب وهوية ووقت. الانتقال لا يحفظ قرارًا.

مرشح فئة الجمع يدخل في التصفية فقط؛ لا يعد وسمًا معتمدًا، ولا يدخل في أعداد الصناديق.

تجهيز لقطة للمسار القائم

بعد اكتمال المراجعات المستقلة لكل عينات الدفعة، تحفظ نسخة جديدة تحتاج تحققًا وتقسيمًا مجمدًا.

لا توجد عينات مطابقة. أضف دفعة بأدوات الاستيراد القائمة أو عدّل التصفية.

الفيديوهات المرجعية

تظهر الملفات المسجلة في الحزمة أو المرتبطة بإطاراتها. جميع إطارات الفيديو تبقى ضمن مجموعة واحدة.

مشكلات تحتاج معالجة

اقتراحات محلية مسجلة، والاعتماد النهائي بشري مستقل.

السحابة معطلة

المراجعة الذكية المسبقة

قائمة موحدة لتجهيز دفعة صغيرة. الاقتراحات آلية؛ التصحيح يؤكده المُعدّ، ثم يراجعه شخص مستقل. لا اعتماد جماعي.

الكشف وOCR محليان. تظهر مقترحات الوجوه واللوحات عند تهيئة الأداة. قد تفوتها بيانات حساسة؛ لا أمتار أو قرارات خصوصية آلية.

معاينة التقرير قبل مشاركته

لا صور أو أسماء ملفات أو نص OCR أو بيانات قياس. افحص الأعداد والتفاصيل قبل إرسال الملف بنفسك إلى ChatGPT. لن يُرسل تلقائيًا. 


          

          

            استيراد صورة اصطناعية مستقلة
            

              لم تُجهز خدمة توليد. ارفع صورة أنشأتها بصورة مستقلة، وسجل المصدر
              والموديل والإعدادات وحقوق الاستخدام. لا تنسخ صورة مرفوضة الحقوق
              ولا تغير اسمها إلى اصطناعية.

              الاختبار النهائي من جلسات حقيقية جديدة.
